# Cadence downloads

Installers for [Cadence](https://cadencemeets.com), published automatically from
the private app repository. This repository holds release files only.

- **Windows 10/11:** [Cadence-Setup.exe](https://github.com/Not-Your-Average-Soy-Boys/cadence-releases/releases/latest/download/Cadence-Setup.exe)
  installs for the current user, with no administrator prompt. Windows SmartScreen
  may warn about an unrecognized app: choose **More info**, then **Run anyway**.

Other platforms are on the [Cadence website](https://cadencemeets.com/#get-cadence).
